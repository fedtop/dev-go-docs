备份与同步 ​

一句话：全部配置可导出为 JSON 再导入（换机 / 备份）；需要跨设备的数据由后台自动分片同步，登录同一浏览器账号即可。

备份（导出 / 导入） ​

设置页「通用 → 数据备份」：

  • 导出配置：生成一份 JSON 文件，包含快捷导航、网络与代理、翻译、AI 模型、划词动作与停用列表、网页增强列表、外观与语言等全部设置
  • 导入配置：选择备份文件立即生效，无效条目会跳过并提示「已导入 N 项（跳过 M 项无效数据）」
  • 备份文件带应用标识和版本号，导入时会校验类型，不是 DevGo 的备份文件会直接拒绝

WARNING

API Key 不写入备份文件（避免明文泄露）。换机导入后，翻译模型和对话模型的 Key 需要在 AI 模型里重新填写。

跨设备同步 ​

不用手动导出导入的部分：登录同一浏览器账号（Chrome 账号的同步），以下数据自动带到其他设备：

  • 快捷导航（新标签页的站点、分类、固定栏）
  • 代理配置（网络模式、代理服务器、规则列表等）

同步在后台自动分片进行，单项数据过大或同步空间满（Chrome 上限 100KB）时会在「通用 → 跨设备同步」里提示；「立即同步」可手动触发。代理是否接管浏览器由各设备自己在网络面板确认，不会随同步强推。

什么用备份、什么用同步？ ​

场景建议
换新电脑 / 重装浏览器导出 → 导入，一次搬完
多台设备日常保持一致登录同一浏览器账号，同步自动完成
只想搬快捷导航新标签页的导入 / 导出（只含导航）更轻量
