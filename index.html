DevGo帮助中心

面向开发者的浏览器效率扩展 —— 翻译、AI 助手、代理与真实 IP 防护、资源嗅探、新标签页。

快速上手（5 分钟）
安装 DevGo

整页双语翻译

译文插在原文段落之后，随滚动按需翻译，支持 Shadow DOM 页面。

划词工具条与自定义动作

划词即得翻译、解释、总结、问 AI，还能添加自己的动作。

AI 助手

侧边栏总结本页、就网页内容提问，支持各家 OpenAI 兼容服务。

真实 IP 防护

开着代理时，防止网站借 WebRTC 拿到你的真实 IP。

代理与自动分流

直连 / 系统 / 自动模式 / 全局代理一键切换，规则自动更新。

资源嗅探与批量下载

嗅探当前页的图片、视频、音频，筛选后批量下载。

悬浮快捷栏

网页右侧的快捷入口：翻译本页、AI 总结、回到顶部。

新标签页

搜索引擎切换 + bang 语法、快捷导航、多种动态背景。

网页增强

按站点解除复制限制，GitHub 代码页悬浮按钮。
