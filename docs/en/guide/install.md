# Install

<!-- TODO(GLM, en translation pass) -->

- **Chrome / Edge**: install from the [Chrome Web Store](https://chrome.google.com/webstore/detail/devgo/kcofdbjhicjdbmldlcffcijglkifnnjn) for automatic updates.
- **Firefox**: download `dev-go-*.firefox.zip` from [GitHub Releases](https://github.com/fedtop/DevGo/releases), unzip, then load it via `about:debugging#/runtime/this-firefox` → Load Temporary Add-on.

See the [Chinese installation guide](/guide/install) for step-by-step screenshots.
