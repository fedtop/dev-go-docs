# 新标签页

<!-- 适用版本：v0.2.3 -->

一句话：搜索引擎切换 + bang 语法（如 `!gh`）、聚合导航与书签的搜索联想、快捷导航分类管理与多种动态背景。

## 搜索：引擎切换与 bang 语法

输入框默认用当前搜索引擎搜索，输入 `!bang 词` 可以**临时**切换引擎搜这一次，不用先改设置：

| 输入                                     | 实际用哪里搜         |
| ---------------------------------------- | -------------------- |
| `!gh react`                              | GitHub               |
| `!npm vite`                              | npm                  |
| `!mdn fetch`                             | MDN                  |
| `!so cors error`                         | Stack Overflow       |
| `!g 关键词` / `!bd 关键词` / `!b 关键词` | Google / 百度 / Bing |

输入的同时会聚合**导航和浏览器书签**的联想结果，常用站点不用进收藏夹。

## 快捷导航

- 预置 **常用 / 开发 / AI / 社区 / 工具** 五个分类，双击分类名可重命名
- 悬停任意站点卡片：编辑、删除、**固定到搜索框下方**（固定栏有上限，满了会提示）
- 添加站点时填名称、网址、选分类即可

导航配置支持**导入 / 导出** JSON：换机、多设备统一布局都靠它；重复的条目导入时自动跳过。新安装用户的默认导航会随版本修订（比如失效链接会被移除），你手动改过的条目永远不会被覆盖。

## 背景与主题

- **动态背景**：流体、神经、柔波、烟环、熔球等 12 种着色器效果，可设「随机」（每次换一个）或「固定」
- **颜色主题**：浅色 / 深色 / 自动，自动指 18:00 – 6:00 用深色；与弹窗、设置页、侧边栏统一生效

## 注意事项

- 快捷导航和代理配置参与[跨设备同步](/settings/sync)：登录同一浏览器账号自动带到其他设备；同步空间有上限（Chrome 为 100KB），导航特别多时可能提示删减
