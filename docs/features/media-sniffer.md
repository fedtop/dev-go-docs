# 资源嗅探与批量下载

<!-- 适用版本：v0.2.3 -->

一句话：嗅探当前标签页的图片、视频、音频资源，按类型筛选、搜索，单个或批量下载。

## 怎么用

打开目标网页，按 `Alt+4`（或点弹窗「资源」页）：

- 自动列出当前标签页加载过的图片、视频、音频；「刷新」重新扫描，「清空」清掉列表
- **筛选**：全部 / 图片 / 视频；**搜索**支持名称、域名、类型
- 每条资源显示来源（请求抓取 / 页面 DOM）和类型，图片和常见格式视频可以直接预览
- 单个下载 / 复制链接 / 打开链接；也可以「下载全部」批量创建下载任务

## 流媒体的说明

视频站大多用 HLS / DASH 流媒体（m3u8 / mpd 清单加分片），DevGo 能识别并展示这类资源，但**不提供拼接下载**：

- 流清单、流分片直接保存得不到完整视频，DevGo 会明确提示并跳过，避免下载无用文件
- X（Twitter）的视频会拆成独立音频轨 / 视频轨，同样提示需要合并后才是完整视频
- 需要完整视频时，复制链接交给 yt-dlp 之类的下载工具更可靠

## 注意事项

- 仅支持 `http` / `https` 协议的资源下载
- 嗅探的是**当前标签页**：切换标签页后列表会跟随新页面，需要保留的先下载
