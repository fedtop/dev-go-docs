# 安装

<!-- 适用版本：v0.2.3；配文：glm2 -->

## Chrome / Edge（Chromium 内核）

推荐从 [Chrome 应用商店](https://chrome.google.com/webstore/detail/devgo/kcofdbjhicjdbmldlcffcijglkifnnjn) 安装，可自动更新。

## Firefox

从 [GitHub Releases](https://github.com/fedtop/DevGo/releases) 下载最新的 `dev-go-*.firefox.zip`，解压后在 `about:debugging#/runtime/this-firefox` 选择「临时载入附加组件」。
