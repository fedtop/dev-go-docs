# FAQ 与故障排查

<!-- 适用版本：v0.2.3 -->

## 划词工具条不出现？

**现象**：选中网页文字，工具条没有浮出来。

**原因**：按网站停用了划词、全局关闭了划词、或只在输入框场景看不到网页类动作。

**步骤**：

1. 打开弹窗「功能」页，看「划词工具条」开关：若显示「已在 xxx 停用」，打开即可
2. 去设置页「划词 → 启用划词」确认全局开关是开的
3. 在输入框里选中文字只会显示写作类动作（润色 / 纠错 / 正式及适用输入框的自定义动作），看不到翻译 / 解释是正常的
4. 都正常还不行：刷新页面再选一次；安装扩展前就打开的页面需要刷新后内容脚本才注入

## 开了真实 IP 防护后，网页会议 / 语音通话连不上？

**现象**：开启防护（尤其「隐藏真实 IP」级别）后，网页版会议、通话变慢或连不上。

**原因**：这是防护的已知代价——网页的音视频连接只能经代理建立，代理不支持 UDP 时更明显。电脑上的会议客户端不受影响。

**步骤**：

1. 设置页「网络 → 真实 IP 防护」，把级别先改回「不防护（浏览器默认）」，刷新网页验证
2. 确认是防护导致后，按需换用「隐藏局域网地址」这类影响更小的级别（真实 IP 仍会暴露，自行权衡）
3. 只在个别网站需要开会？可以临时切回「不防护」，开完会再改回来

详见[真实 IP 防护](/features/ip-protection)。

## Firefox 里代理切换不可用？

**现象**：Firefox 构建里切换网络模式没有效果。

**原因**：DevGo 的代理控制基于 Chromium 的 `chrome.proxy` 设置接口，Firefox 的实现与配置格式不同，暂未适配。

**步骤**：

1. Firefox 下请使用系统代理或代理软件自身的分流
2. 真实 IP 防护、CORS 调试等其他网络功能不受此影响
3. Firefox 的代理适配在计划中，可到 [Issues](https://github.com/fedtop/DevGo/issues) 关注进展

## 网页工具（WebMCP）里什么都没有？

**现象**：侧边栏「网页工具」页提示不支持、读取不到或没有工具。

**原因**：WebMCP 是 Chrome 150+ 的实验功能，需要手动开启；且网页本身要通过 WebMCP 注册工具。

**步骤**：

1. 确认 Chrome ≥ 150
2. 打开 `chrome://flags`，搜索「WebMCP for testing」，启用后重启浏览器
3. 普通网页本来就没有工具属正常；不确定时点「重新检测」

详见[网页工具（WebMCP）](/features/webmcp)。

## AI 报 401 / 404 / 429 怎么办？

**现象**：划词 AI 动作、侧边栏助手或 AI 翻译报错。

**原因与步骤**（按错误码）：

| 报错            | 含义                                     | 处理                                                         |
| --------------- | ---------------------------------------- | ------------------------------------------------------------ |
| 鉴权失败 / 401  | API Key 无效，或不属于当前接口地址的服务 | 核对 Key；刚切换服务预设的，确认 Key 来自该服务              |
| 404             | 接口地址或模型名不存在                   | Base URL 填到 `/v1` 即可（会自动补全）；模型名对照服务商文档 |
| 429             | 请求过于频繁或额度不足                   | 稍后重试；检查账户额度与并发限制                             |
| 连接失败 / 超时 | 网络不通或地址写错                       | 检查网络（是否需要代理）；用「测试连接」验证                 |

配置入口：设置页「[AI 模型](/settings/models)」。

## 整页翻译没有译文？

**现象**：点了「翻译当前页面」，页面没变化或部分段落没有译文。

**步骤**：

1. 目标语言设为「自动」时，中文页面会译成英文、其余译成简体中文——翻译成「同一种语言」时看起来像没生效，换明确的目标语言试试
2. 引擎不可达：Google 引擎需要代理；微软引擎免翻墙。弹窗里切换引擎再试
3. 选了「AI 大模型」但未配置 / Key 失效：弹窗会提示「还没有配置翻译模型」，去配置或先切回微软
4. 部分段落失败：段落后面有 ↻ 可单独重试；仍失败换引擎
5. 浏览器内置页、扩展商店不支持翻译，属正常限制

## 扩展更新后被浏览器停用了？

**现象**：更新 DevGo 后浏览器提示扩展被停用 / 需要重新确认权限。

**原因**：浏览器对新旧版本**权限差异**的处理，DevGo 的 `privacy` 是可选权限，仅在你开启真实 IP 防护时才申请，不会因它触发停用；若未来版本新增普通权限，浏览器按规则要求你重新确认。

**步骤**：在 `chrome://extensions` 的 DevGo 卡片上按提示重新启用即可，配置与数据不受影响。

## 如何回到默认设置？

**现象**：想清掉所有自定义配置，回到全新状态。

**步骤**：

1. 没有一键重置入口。单个功能在对应设置页逐项改回即可（如划词动作逐个删除、停用列表逐个移除）
2. 想彻底重来：移除扩展后重新安装，本机数据（划词动作、代理配置、停用列表、API Key）会全部清空，恢复默认
3. 反向操作前建议先「导出配置」留底，配错了一键导入即可恢复

## 在哪提功能建议 / 报 bug？

**步骤**：到 [GitHub Issues](https://github.com/fedtop/DevGo/issues) 提交。报 bug 时带上：浏览器与版本、DevGo 版本（设置页或 `chrome://extensions` 可查）、复现步骤和报错截图，能显著加快定位。
