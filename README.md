
# DevGo Docs

这是 DevGo 的 VitePress 文档站。DevGo 是一个面向开发者的浏览器效率扩展，聚焦翻译、GitHub 增强、新标签页效率工具、网络调试辅助和页面资源处理。

文档站：👉🏻 [DevGo 使用文档](https://fedtop.github.io/dev-go-docs)

源码仓库：👉🏻 [DevGo](https://github.com/wangrongding/dev-go)

## 文档内容

- 首页：概览当前扩展能力。
- 使用指南：说明 Popup、新标签页、页面增强、快捷键和备份同步。
- 本地开发：说明 DevGo 代码仓库的启动、构建、结构和主要权限。

## 本地预览

```bash
pnpm install
pnpm docs:dev
```

## 构建

```bash
pnpm build
```
