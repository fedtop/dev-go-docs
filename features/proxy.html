代理与自动分流 ​

一句话：直连 / 系统代理 / 自动模式 / 代理模式一键切换，也可以新增自定义代理模式；每种模式分别保存代理服务器和绕过列表。

四种网络模式 ​

模式行为
直连不使用代理
系统代理跟随系统设置
自动模式按规则自动分流：命中规则走代理，其余按你选的默认去向
代理模式全部流量走代理

入口：弹窗「网络」页（Alt+3）一键切换；设置页「网络」做完整配置。

单站点快捷切换 ​

弹窗「网络」页底部有当前网站的快捷开关：

  • 当前站点直连：临时让某个网站绕过代理（比如代理下访问不了国内站）
  • 当前站点走代理：只让当前网站走代理（自动模式的「自定义代理域名」同理，优先于规则列表）

自动模式详解 ​

自动模式 = 规则列表 + 自定义域名 + 默认去向：

  • 规则列表：AutoProxy / GFWList 格式，启用后命中规则的站点走代理，每 6 小时自动更新，也可手动「更新 / 下载」
  • 自定义代理域名：规则没收录但需要走代理的站点，每行一个域名（自动包含子域名）
  • 未命中规则时：默认「直连」（只有命中才走代理）；如果你的代理软件自带分流，可以改成「走代理」——除绕过列表、局域网和 .cn 域名外全部走代理

没有任何规则、也没有自定义域名时，自动模式等于直连。

自定义代理模式 ​

除了内置模式，可以「新增自定义模式」，给不同的代理服务器起名（如「工作」「家庭」），一键互相切换。每个模式独立保存代理服务器（协议 / Host / 端口）和绕过列表。

注意事项 ​

  • 代理服务器与绕过列表修改后要点「保存并应用」才生效；规则列表、代理域名和真实 IP 防护即时生效
  • 代理配置保存栏吸底显示，有未保存修改时会高亮提醒，离开前会确认
  • 开启「切换代理后刷新页面」，在弹窗切换模式后当前网页自动刷新，避免新旧连接混用
  • DevGo 接管代理后，浏览器扩展卡片会显示「已由 DevGo 控制」；若显示「被其他扩展控制」，需要先停用那个扩展
  • Firefox 暂不支持代理切换（Chromium 专有 API 限制），见 FAQ
